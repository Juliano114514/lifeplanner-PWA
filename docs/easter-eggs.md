# 彩蛋与历史记录

首页连续点击同一用户卡片任意位置五次（相邻点击不超过 1 秒，单击同时选中用户），打开属于该用户的最新彩蛋；切换用户卡片或超过间隔后重新计数；没有文案、图片或录音时隐藏对应内容区域，不显示占位提示。显示作者名称及已有内容。作者名称按保存时快照记录。

“我也要写”直接读取本人最新彩蛋并打开编辑器，以应用时区（当前为 Asia/Shanghai）比较最后修改时间：同日预填文案、图片和录音；次日 0 点后再次打开时清空新建。正在编辑的未保存草稿不在午夜强制丢弃，保存按服务端接收时所在日期归档。服务端拒绝写入其他成员的彩蛋；取消不保存。三个内容至少填写一项，正文最多 10000 字符。图片支持 PNG/JPEG/GIF/WebP，超过 10 MiB 拒绝上传，不压缩 GIF；录音最多 15 秒，可主动停止，离开页面/取消时关闭麦克风，录音文件上限 1 MiB。麦克风需用户授权；未获得权限时仍可保存文案或图片。

历史记录每人每天只保留最后保存的完整内容，按保存顺序倒序分页，每页 30 条，仅拉取文案和图片名称等摘要。当天再次保存会在同一事务中清除前一次文案和媒体并替换当天记录，旧 ID/哈希只作重试保护，不再是可读历史。点击再加载完整媒体；每次重试使用同一保存编号，防止网络超时后重复追加；重试已被覆盖的旧保存会提示重新打开编辑器，不覆盖当天的新内容。彩蛋读取与保存需要联网，保存失败时保留当前编辑器内容供重试，取消或离开编辑器不保存草稿。

## 短时读取缓存

PWA 按登录用户和完整查询地址缓存历史分页、最新彩蛋及详情，复用 15 秒内的成功响应，并合并同时进行的相同读取。反复打开同一彩蛋、关闭详情返回历史时，命中缓存不再请求 Worker，因而省去该请求的认证、历史及媒体数据库读取。失败响应不缓存，过期后重新联网读取，不提供离线彩蛋副本。

仅使用页面内存，最多 12 个响应，按 JSON UTF-16 大小估算的载荷总量不超过 12 MiB（不代表整个页面的堆内存上限）；优先淘汰过期和最久未访问的响应。媒体仍按需加载，未打开的详情不预取。缓存命中不延长有效期。

保存、删除前后都清空缓存并通过 BroadcastChannel 通知同源页签，即使写请求超时也清空，避免服务端已提交而本机继续使用旧缓存。失效前发出的读取不能把旧响应重新放入缓存。开始手动或自动同步、页面可见性变化、断网及恢复联网也清空缓存；下一次读取访问服务端。跨设备变更不发送浏览器广播，因此在没有其他失效事件时，再次打开可能复用尚未满 15 秒的响应。已打开页面仍保持原有刷新时机，缓存过期本身不触发后台拉取，也不覆盖编辑器草稿。

任务、生活记录和资料继续使用现有 IndexedDB、待同步队列、版本与冲突规则；API、D1 schema 和 Service Worker 的 API 排除规则不变。本次缓存无需新迁移，更新应用或重新加载页面后自动丢弃；不能把网页静态检查视为鸿蒙或其他设备的同步实测。

## 发布要求

新增 `migrations/0004_eggs.sql`，包含 `eggs` 和 `egg_media` 表。媒体按 256 KiB 的 Base64 字符块保存，一次 D1 batch 原子写入快照与全部媒体，避免单行存入整个 10 MiB 图片。没有新增存储服务或凭据。

上线前先执行 `npm run db:remote`，再按 README 的构建部署流程发布前端与 Worker。本次代码提交不等于远端迁移或部署已完成。迁移只新增表和索引，不修改已有任务/日程/资料。

## 接口

- `GET /api/v1/eggs/latest?owner=<成员ID>`：该成员最新内容。
- `GET /api/v1/eggs?before=<游标>`：历史摘要与下一页游标。
- `GET /api/v1/eggs/<记录ID>`：历史详情，包括媒体。
- `POST /api/v1/eggs`：`{ id, draft: { text, image, audio } }`，媒体为 `{ name, mime, data }`，`data` 为 Base64；可空的媒体传 `null`。

所有接口复用现有双用户会话认证。写入额外校验 Origin 和 `X-LifePlanner-Actor`。录音计时由前端控制；后端验证媒体格式声明和大小，不解析音轨时长。

静态校验包括 TypeScript、ESLint、SQL 内存检查（媒体分块还原、事务失败回滚、同时间历史分页）。尚需在实际 Safari/Chrome 上验收麦克风授权、15 秒截止、GIF 播放、音频播放与双账号历史读取。

录音 MIME 校验兼容 codecs 参数中的空格与引号，读取 Data URL 时从最后一个逗号后提取 Base64，避免多 codec 声明截断数据。前后端共用格式校验，空内容提示与媒体校验失败提示分开。

录音事件处理参考 [MDN MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder)。

## 归属、删除与同步时间

`0005_member_sync_egg_owner.sql` 增加用户同步时间表及彩蛋归属、删除标记。旧彩蛋归属初始化为原作者。新版本发布前应先运行数据库迁移；旧版保存接口仍可不传 ownerId，此时归属当前作者。

首页显示服务端持久化的最后成功同步时间，一轮任务、日程和资料同步成功后调用 `POST /api/v1/sync/complete`，写入当前用户时间并返回双方时间。离线通过已有账号 IndexedDB 缓存读取，不用任务修改时间伪造同步时间。不足 1 分钟显示 `X秒前`，不足 1 小时显示 `X分钟前`；1 至 24 小时内显示整数 `X小时前（HH:mm）`，之后沿用天数/月日格式。

保存彩蛋可传 `ownerId`，但必须为当前登录用户；`latest?owner=` 按归属读取，标题仍显示实际作者。双方共用历史列表。长按 600 毫秒或桌面右键/键盘 Delete 后弹窗确认；移动超过 10px 或系统取消触控时终止长按。确认后调用 `POST /api/v1/eggs/<id>/delete`，双方共享成员均可删除。服务端原子清除文案与媒体，只保留保存编号/哈希等去重信息，防止旧请求重试复活已删除内容。删除最新一条后会显示该归属人的上一条未删除记录。

## PWA 媒体权限

图片通过原生文件选择器选取，不申请麦克风或相册整库读取权限；部分系统文件提供器不返回 MIME 类型，因此按文件头识别 PNG/JPEG/GIF/WebP。图片限额为 10 MiB。

录音只在点击开始时请求麦克风。授权等待可取消，30 秒没有结果时恢复可操作状态；取消后即使迟到的授权成功，也立即关闭返回的音轨。授权等待期间选择图片会取消该轮录音等待。权限返回时如果应用仍在后台，提示返回应用重试，不静默失败。

若提示权限被拒绝，需要检查 PWA／安装浏览器的站点权限以及系统麦克风权限；网页无法强制弹出被禁用的权限请求。区分未授权、没有麦克风、麦克风不可用和非安全连接。该处理不代表所有手机浏览器的权限弹窗已经实测。

权限行为参考 [MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)。

## 按日归档迁移

发布本版前需执行 `0006_daily_eggs.sql`（`npm run db:remote`）。迁移按现有部署的北京时间回填日期，同一归属人同一天保留最后修改的一条（时间相同时取最后保存的序号），清除其他版本的正文与媒体，仅保留去重信息；唯一索引保证每天最多一条有效记录。此前已经删除的记录不参与保留。新保存使用服务端配置的应用时区计算日期。

本次不自动执行远端迁移；应先备份再迁移并发布。当天删除后重新写入仍归档到当天，删除当日最新内容不会恢复当日已经被替换的旧版本。
