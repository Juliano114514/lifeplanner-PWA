## 配置后的人工验收清单

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 白名单 | 两个指定账号和第三个账号分别登录 | 前两者成功，第三者拒绝且无任务访问权 |
| 归属与协作 | A 新建归属 B，B 修改内容/完成/归档 | 两端一致；创建人 A 不变，最后修改人 B |
| 重复规则 | 每日、每周；1 月 31 日开始的每月任务 | 无重复实例；月末截断后下月恢复原日号 |
| 修改重复任务 | 先完成/跳过某些日期，再改变模板 | 历史和非待办状态保留，今天起待办按新规则重建 |
| 分组排序 | 置顶、过期、三天内截止、今日完成、其他 | 与安卓现有 TodoOrganizer 分支和排序一致 |
| 任务安排 | 从任务操作进入日程，调整时间并完成/恢复 | 日程与任务实例的完成状态同步变化 |
| 日程 | 新增重叠日程、编辑、完成、归档 | 24 小时时间轴显示且重叠项标注“时间冲突” |
| 快速安排 | 依次填写/跳过八张卡片并生成 | 生成可编辑日程；“其他”创建当日待办 |
| 日记 | 同日添加两类条目和正文后保存 | 条目与正文一次保存；换日返回后内容仍在 |
| 菜品 | 新增临期食材并降低余量 | 同时出现临期和需要补货文字状态，采购清单自动加入 |
| 库存采购 | 三种记录方式各新增一项，完成采购并填写购入量 | 状态显示正确；关联库存余量同步回写 |
| 生活数据冲突 | 两设备同时修改日程与日记 | 保留本机队列，整体采用云端或在新版上重放本机操作 |
| 恢复待办 | 在操作与记录中恢复已完成/已跳过实例 | 变为 PENDING，完成时间清空 |
| 离线重开 | 在线登录后断网，新建/修改，关闭再打开 | 草稿、任务和待同步队列仍在 |
| 重复提交 | 服务端已接受但客户端未收响应后重试 | 同 mutation ID 不重复执行，不重复生成任务 |
| 冲突 | 两设备基于同版本修改相同任务 | 409 后保留双方内容，用户显式选择 |
| 长时间编辑 | A 打开编辑页，B 保存更新，A 收到同步后才保存表单 | A 仍提交打开编辑页时的版本，必须触发冲突而非自动覆盖 |
| 归档冲突 | A 归档，离线 B 编辑后联网 | 不复活原任务；可把本机模板另存为新任务 |
| 会话过期 | 过期后编辑，再登录相同账号 | 上传暂停，本机队列保留，登录后继续 |
| 切换账号 | A 有未同步队列，退出并登录 B | 不以 B 身份上传 A 队列；重新登录 A 可恢复 |
| 多页签 | 两个页签同时提交 | Web Locks 协调；幂等/版本检查防止重复和覆盖 |
| 日历时区 | 设备时区不同，共享时区相同 | 计划日期与重复规则一致，界面标注共享时区 |
| 更新 | 存在编辑草稿时发布新版本 | 编辑时禁用更新按钮；关闭编辑后更新保留草稿和队列 |
| iPhone | 主屏幕打开，弹键盘，横竖屏切换 | 安全区、导航、编辑页可用，无内容横向溢出 |

部署前确认备份和目标数据库；健康检查 200 不替代上述验收。
